# Памятка сотрудника IAD · Memphis

**Создатель: Marcus Nomad · редакция 1.0 от 17.10.2026**

## Открыть памятку

Скачайте **[Памятка IAD — Marcus Nomad.html](Памятка%20IAD%20%E2%80%94%20Marcus%20Nomad.html)** и откройте файл в современном браузере. GitHub показывает исходный HTML, поэтому для использования скачайте файл через **Download raw file**. Интернет и установка не нужны; переходы на форум требуют интернета.

В одном файле:
- быстрые маршруты квалификации и пределы полномочий IAD LSPD;
- чек-лист внутренней проверки и копируемый шаблон заключения;
- задержание, права, особая процедура по госслужащим, освобождение и арест;
- стадии силы и ограничения;
- поиск по УК, АК, ДК, ПК, уставу LSPD, ЭК, ТК и связанным законам;
- 849 карточек статей / вводных блоков из 19 профильных разделов;
- точные тексты, части, санкции, исключения, исходные форумные ссылки и номера абзацев DOCX;
- отдельный разбор исправлений и неоднозначностей первоисточника;
- печать текущего раздела (перед печатью норм раскройте нужные карточки).

Отметки чек-листа временные и не сохраняются. Никакие данные не отправляются в сеть. Не используйте распространяемую копию для хранения персональных или секретных материалов.

## Источники и ограничения

Три исходных файла в `Памятка/` оставлены без изменений. Нормативный приоритет при подготовке — у `clean_Majestic РП Memphis.docx`; текст ИИ проверялся как черновик, XLSX — как устаревший образец. Актуальность означает соответствие **предоставленному срезу DOCX**, а не онлайн-проверку форума.

Алгоритмы не вводят новых полномочий и не заменяют полный текст. Особо отмечены спорные единицы срока в УК 5.2, терминология составов в уставе и некорректная отсылка в ПК 20. Автоматического расчёта наказания нет. Правила сервера отделены от IC-законодательства; релевантные выдержки приведены в разделе источников.

## Воспроизводимая сборка

```sh
python -m venv .venv
.venv/bin/pip install -r tools/requirements.txt
.venv/bin/python tools/build_memo.py
.venv/bin/python tools/test_source.py
```

DOM-проверки интерфейса (Node.js 22+):

```sh
npm install --no-save --package-lock=false jsdom@30.1.3
node tools/test_memo.cjs
```

Проверки: покрытие всех заголовков статей выбранных разделов, дословное совпадение тел статей с DOCX, уникальность ID, отсутствие внешних ресурсов; навигация, поиск и фильтры, пустая выдача, редакционные ссылки, раскрытие / сворачивание, чек-лист и отсутствие ошибок JavaScript. Это структурные и DOM-тесты, не полноценный визуальный браузерный тест.

Для обновления нормативного среза необходимо проверить соответствие позиций разделов в `tools/build_memo.py`, пересобрать файл и **вручную пересмотреть редакционные алгоритмы, оговорки и дату** в `tools/memo_template.html`. Простая замена DOCX без правовой сверки не гарантирует актуальность памятки.
